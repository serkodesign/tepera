# Концентричність радіусів (аудит 26.11.2026, виправлення застосовано того ж дня)

Правило: **радіус зовнішнього = радіус внутрішнього + відступ між ними.**
Якщо відступ ≥ радіуса зовнішнього — концентричність не потрібна (внутрішній може бути прямим).
Для кола/пілюлі внутрішній радіус = половина його висоти.

Картки (`TeperaCardVariant`): Standard 16/16, Context 24/16, Hero 28/20 (радіус / відступ).
Звідси радіус вкладеного елемента всередині картки: Standard — n/a, Context — 8, Hero — 8.

## Конфлікт у картці пауз (№1 і №10)

Ланцюжок картка → рядок → кнопка: 24 → X → 16, відступи 16 і 8.
Для обох ланок одразу потрібно: рядок 24 (для кнопки) і рядок 8 (для картки). Одночасно не вийде.
Концентричними можуть бути обидві ланки, лише якщо картка Context має радіус 40 (24 + 16).

Варіанти:
- **А (зараз):** концентрична ланка «рядок → кнопка», картка → рядок не концентрична.
- **Б:** радіус картки пауз 40 (лише для неї, поза шкалою).
- **В:** відступ між карткою і рядком зменшити з 16 до 0 (рядки на всю ширину картки) — тоді вимога зникає.
